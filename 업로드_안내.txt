해피랜드 공인중개사사무소 홈페이지 - 로고형 첫 화면 / 사진 갤러리 개편

이 압축파일은 '고객용 공개 홈페이지'입니다. GitHub에 업로드할 수 있습니다.

업데이트 순서
1) 이 ZIP을 모두 압축 풉니다.
2) GitHub 저장소 https://github.com/pigwkd5908-ship-it/pigwkd5908-ship-it.github.io 으로 이동합니다.
3) Add file > Upload files 에서 압축 해제한 폴더의 파일 전체와 images 폴더를 선택합니다.
4) Commit changes 후 GitHub Pages 게시 완료를 확인합니다.
5) https://pigwkd5908-ship-it.github.io/ 에 접속해 Ctrl + F5 를 눌러 확인합니다.

유지/변경 사항
- 기존 59개 광고 링크와 필터, 101호 상세 페이지를 유지합니다.
- 첫 화면 추천 매물 영역을 없애고 HAPPY LAND 공식 로고와 사무소 정면 사진을 사용합니다.
- 사무소 소개에 보조 외관 사진을 사용합니다.
- 각 매물은 images 배열이 있으면 여러 장의 사진을 갤러리로 보여줍니다.
- 관리자 프로그램에서 입력한 매물은 listings-data.js와 images 폴더로 업데이트합니다.
- 메인 사진은 과거 촬영 사진으로 간판 연락처/대표 표기가 현 등록증과 다를 수 있습니다.

보안: manage.html/manager.js 파일은 이 ZIP에 포함되지 않습니다.
