해피랜드 여러 플랫폼 매물 사진 등록 안내

홈페이지 주소: https://pigwkd5908-ship-it.github.io/

현재 직방/피터팬/다방은 광고 대표사진 원본이 제공되지 않아 사진 대신 안내 이미지가 나옵니다.

1. 본인이 보유하거나 사용 권한이 있는 해당 광고의 첫 번째 매물 사진(JPG)을 준비합니다.
2. 파일 이름을 해당 플랫폼의 광고번호로 변경합니다.
   예) 직방 광고 50599187 -> 50599187.jpg
   예) 피터팬 광고 20068572 -> 20068572.jpg
   예) 다방 광고 DB-VKGT -> DB-VKGT.jpg
3. 현재 폴더(images/listings)에 사진을 넣습니다.
4. GitHub 저장소 pigwkd5908-ship-it.github.io 에 동일한 경로로 파일을 업로드합니다.
5. GitHub Pages 반영 후 브라우저 Ctrl+F5 새로고침하면 카드 사진이 자동으로 나타납니다.

주의: 광고 URL만으로 외부 플랫폼의 사진을 자동으로 받아 오는 기능은 아닙니다.
타 매물의 사진을 잘못 연결하지 않도록 광고번호를 확인하세요.
이미지 활용 권한 및 정보 정확성을 확인해 주세요.
