해피랜드 고객용 홈페이지 V3

1. 이 ZIP을 압축 해제합니다.
2. 내용물 전체(index.html, script.js, styles.css, property.html, property.js, listings-data.js, images 폴더 등)를
   GitHub 저장소 https://github.com/pigwkd5908-ship-it/pigwkd5908-ship-it.github.io 에 업로드합니다.
3. Commit changes → GitHub Pages 게시 완료 → Ctrl+F5로 확인합니다.
4. 향후 매물만 추가·변경할 때는 관리자 프로그램에서 만든 게시용 ZIP의 데이터/사진만 추가 업로드하면 됩니다.

기존 59건 및 기존 101호 상세페이지를 유지합니다.
새로 추가되는 property.html + property.js는 주소, 층, 면적, 관리비 항목, 사진 등을 표시합니다.
'확인 필요'로 표기된 정보는 게시 전 반드시 확인하고 보완하세요.
법정 표시사항의 진위는 관리자가 직접 검증해야 합니다.
