해피랜드공인중개사사무소 — 플랫폼 링크/리뷰 연결 개편본

반영 저장소: https://github.com/pigwkd5908-ship-it/pigwkd5908-ship-it.github.io
최종 홈페이지: https://pigwkd5908-ship-it.github.io/

추가된 기능
- 매물광고 총 59개 링크 모아보기 (중복 매물 포함 가능)
- 가격을 확인할 수 있는 매물은 보증금/월세 표시
- 당근 광고에서 확인된 일부 사진을 링크로 표시 (외부 호스팅/접근 제한 시 자동 대체)
- 직방/다방 가격 미확인 광고는 가격 임의 표기 없이 외부 링크 안내
- 피터팬 32개 링크 및 공개 광고 제목에 표시된 가격
- 네이버 플레이스 방문자 리뷰 바로가기 / 당근 공개 후기를 구분해 연결
- 집품/당근/다방 사무소 링크
- 검색/플랫폼/보증금/정렬 필터 / 모바일 반응형
- 기존 101호 상세 페이지와 사진 6장 유지
- robots.txt / sitemap.xml 포함

업데이트하기
1. ZIP 압축을 완전히 풀기
2. 폴더 안의 파일과 images 폴더를 모두 선택
3. GitHub 저장소 Code > Add file > Upload files
4. 파일과 images 폴더를 업로드하고 Commit changes
5. 홈페이지 새로고침(Ctrl + F5)

주의 사항
- 실제 매물 정보의 자동 연동/실시간 갱신이 아닙니다.
- 가격/계약 여부는 광고 등록 이후 달라질 수 있으므로 게시 전 재확인하세요.
- 네이버 방문자 리뷰의 실제 본문은 공개적으로 확인되지 않아 가짜 후기를 생성하지 않았습니다.
- 당근 공개 평점(4.0, 후기 4건)은 2026-10-23 페이지 확인 시점의 값입니다.
- 당근 사진은 당근 원본 서버의 썸네일을 사용하는 방식이므로 링크가 변경되면 표시되지 않을 수 있습니다.
- 네이버 소유확인 인증파일은 이 ZIP에 포함되지 않습니다. 네이버에서 발급받은 파일을 별도 업로드하세요.
